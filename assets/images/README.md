# assets/images

Placeholder images are loaded directly from the Pexels CDN (see the project root
[IMAGES.md](../../IMAGES.md) for the full list, source links, and credits).

If you prefer to host images locally instead of loading them from Pexels, drop
your files in this folder and update the `src` / `url(...)` references in the
HTML files and `css/style.css`.

Suggested filenames (matching the original prompt):

```
hero.jpg       about.jpg      chef.jpg       logo.png
dish-1.jpg     dish-2.jpg     dish-3.jpg
gallery-1.jpg  gallery-2.jpg  gallery-3.jpg
```
