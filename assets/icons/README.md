# assets/icons

Favicons and app icons live here.

The site currently uses an inline SVG favicon (defined directly in each HTML
`<head>` via a data URI), so no icon files are required to run the project.

To use your own icon files instead, place them here and replace the
`<link rel="icon" …>` tag in each HTML file, e.g.:

```html
<link rel="icon" type="image/png" href="assets/icons/logo.png" />
```
